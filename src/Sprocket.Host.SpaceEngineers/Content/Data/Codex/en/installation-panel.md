# Installation panel

The installation panel is where an ![](mark:installation) [installation](#installation) gets its blocks and ![](mark:signal) [signals](#signal). Each installation has its own. It also shows what whoever made the ![](mark:logic-system) [logic system](#logic-system) wrote about it, so that someone who has never seen it can install it.

## Opening it

On the [home screen](#home):

- press `+ installation` under a logic system, to add an installation and fill its slots, or
- press an installation's row, to change its blocks.

A logic system put on this [construct](#construct) from the [library](#library) comes with one installation, with nothing filled in yet. Press its row to fill it.

## What it shows

- **The installation's name**, which you can change, and the logic system it belongs to. Pressing the logic system's name opens it.
- **The description** of the logic system, written on its screen.
- **What is wrong**, if anything, with a button that opens the ![](mark:sequence) [sequence](#sequence) where it went wrong.
- **The slots**, with how many still need a block.

Each [slot](#slot) shows its name, what it is for, and what fills it now. A signal slot also shows the toolbar slot that sends its signal, for example `button 2 is pressed`. A slot whose block was lost says so, and names the block.

The names and what each slot is for are written on the logic system's screen and each slot's page, once for every installation.

## Filling the slots

Press a slot to [pick](#picking) what fills it. Only blocks of a kind the slot expects are offered. For a signal slot, you pick the block and the toolbar slot, and that toolbar slot is set up for you.

Slots are filled while the installation or its logic system is switched off. While both are on, the installation can run, and the panel says so. The installation's switch is on the panel as well, so you can switch it off to fill it, and on again as soon as every slot is filled.

## Filling a slot again

Slots are worked out again after every change to the logic system, so a slot this installation filled can be split in two, or merged into a bigger one. Each slot that changed reads `Changed: fill it again` in place of its blocks, and the heading over the slots counts them, for example `1 slot to fill again`.

The blocks the installation had are set aside, and listed under the slot after `Set aside, offered first:`. Press the slot, and the picker lists them first, each marked `Set aside`. Choose the ones that belong in this slot.

The blocks set aside are kept until every slot of the installation is filled again, and then let go.
