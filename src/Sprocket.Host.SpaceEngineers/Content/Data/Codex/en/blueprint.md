# Blueprint

A blueprint is a copy of a ![](mark:logic-system)&nbsp;[logic system](#logic-system) kept in the [library](#library), so you can put it on other constructs, wherever you are. It holds the logic system's ![](mark:sequence)&nbsp;[sequences](#sequence), [triggers](#trigger) and [slots](#slot) and what you wrote about them, but no blocks: each construct brings its own through its ![](mark:installation)&nbsp;[installations](#installation).

The library is where you make and update blueprints, put them on constructs, copy them and share them.

A logic system already on a construct travels with it, so a ship pasted from a grid blueprint brings its automation along.

::: player
Your blueprints are saved on your computer, so every world you play on it can use them. Sharing reaches the engineers in the world you're in. To take a blueprint to another computer, or to a friend who plays elsewhere, copy its file:

1. Paste `%AppData%\SpaceEngineers\Storage` into the address bar of File Explorer to open the folder.
2. Copy the blueprint's file. Its name starts with `sprocket-bp-`, for example `sprocket-bp-Airlock.cog`.
3. On the other computer, put the file in the same folder, then open `sprocket-bp.index` there and add the file's name on a line of its own.

The blueprint shows up in the library the next time a world is loaded.
:::
