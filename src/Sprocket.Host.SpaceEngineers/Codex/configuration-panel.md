The configuration panel is where an [installation](#installation) gets its blocks and [signals](#signal). Each installation has its own. It is also where whoever made the [logic system](#logic-system) explains it, so that someone who has never seen it can install it.

## Opening it

On the [home screen](#home):

- press `+ installation` under a logic system, to add an installation and fill its slots, or
- press an installation's row, to change its blocks.

A logic system put on this [construct](#construct) from the [library](#library) comes with one installation, with nothing filled in yet. Press its row to fill it.

## What it shows

- **The installation's name**, which you can change, and the logic system it belongs to. Pressing the logic system's name opens it.
- **The description** that whoever made the logic system wrote.
- **What is wrong**, if anything, with a button that opens the [sequence](#sequence) where it went wrong.
- **The slots**, with how many still need a block.

Each [slot](#slot) shows its name, what it is for, and what fills it now. A signal slot also shows the toolbar slot that sends its signal, for example `button 2 is pressed`.

## Filling the slots

Press a slot to [pick](#picking) what fills it. Only blocks of the right kind are offered. For a signal slot, you pick the block and the toolbar slot, and that toolbar slot is set up for you.

The installation's switch is on the panel as well, so you can switch it on as soon as every slot is filled.

## Setting up the panel

Whoever makes a logic system sets up what its configuration panel says. `Edit configuration panel`, on the logic system's screen, opens it for that. The logic system must be switched off first.

- **The description** says what the logic system does and what whoever installs it needs to know. It can have headings, lists, and bold or italic text, and is also shown beside the [blueprint](#blueprint) in the library.
- **Each slot's name** is what everyone filling it sees. Two slots can't have the same name.
- **Each slot's line on what it is for** tells them which of their blocks to choose.

These are written once, and every installation's panel shows them. Nothing is filled while setting up the panel.

Write it for someone who has never seen your construct. A slot starts with the name of the block you picked, such as *Interior Door 2*, which tells whoever fills it nothing. Rename it *Inner door* and describe it as the door on the pressurized side, and whoever fills it knows which door to choose.
