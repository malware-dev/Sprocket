# Standing rules

Rules that govern everything Sprocket is, rather than any one part of it. Every ticket is judged
against all of them, and a ticket that cannot meet one says so.

## Everything Sprocket is responsible for survives a save and a reload

Anything a running system holds and then forgets when a world is reloaded is indistinguishable from
a bug in the thing that held it. This covers the program, what a running system has reached, and
anything recorded on the way.

## The first part of a split restricts what can be built, never what can be represented

Where a job is done in pieces, the model, the stored form and the evaluation carry the whole shape
from the first piece. The editor offers a subset.

A trigger held inside a sequence cannot be shared by two of them, however the editor is written.
Restricting the editor costs nothing; restricting the model costs every program already saved.
