# The screens, held still.
#
# A handful of screens meant to stay as they are, each kept whole so any change to one shows. The
# guard for everything else is the presentation tests, which press and read by name and assert what
# matters on each screen.
#
# One line per state: a name, then what to do to get there. Everything is pressed by what the screen
# says (press <text>, a symbol included), never by where it is, so a layout that moves does not send
# a press somewhere else.
#
# Every entry starts from a construct that remembers nothing, so the whole suite is a walk through
# the product from empty. Nothing here depends on what anybody last built in the windowed simulator,
# and nothing here writes into it.
#
# Run with:
#   dotnet run --project src/Sprocket.Host.SpaceEngineers.Sim -- --suite tests/Reference/suite.txt tests/Reference/frames
#
# The dumps in frames/ are committed, so `git diff` is the comparison: an empty diff means nothing on
# any screen moved.
